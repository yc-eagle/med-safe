## 命名约定

```
raccoon-shots/
├── 01-<用途简写>.png
├── 02-<用途简写>.png
├── 03-output.png          ← 一次"验证并拒绝"的小浣熊输出
├── 04-lookup-failed.png   ← 拿去规则库核对，查不到
└── 05-our-substitute.png  ← 我们改用的方案
```

**每个文件名都要在 `raccoon-usage-log.md` 的对应记录里被引用。**

---

## ⭐ 必须凑齐的一组（3 张）

「验证并拒绝」事件的完整证据链：

- [ ] **输出** —— 小浣熊给了什么
- [ ] **核对失败** —— 拿去我们自己的规则库 / 实现里验证，对不上
- [ ] **我们的替代方案** —— 我们改用了什么

> 这三张图是 Raccoon Work 奖 30% 评分（*validation of AI-generated outputs*）的核心证据，
> 也是路演里"我们按同样的标准审查了自己的工具"那句话的实物支撑。
