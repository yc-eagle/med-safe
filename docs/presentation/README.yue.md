## 我哋想幫到嘅一刻

長者睇完唔同門診，帶住幾款藥返屋企，屋企人或者照顧者幫手整理。之後想加一款傷風藥或者止痛藥：手上究竟係邊款藥、有乜成分、有邊啲問題應該先問藥劑師？

字細、醫學用語同語言差異，都可能令呢件事變得困難。藥盒亦唔等於個人處方，藥袋或者醫護人員嘅指示可能有唔同用法。呢啲係產品想支援嘅情境；有幾常見、影響有幾大，仲要靠真實使用者研究去了解。

我哋由香港出發，用本地 HK 註冊編號、中英文藥品資料同廣東話，將**最初嘅資料核對同問藥劑師之前嘅準備**帶到屋企，幫長者同照顧者問得更清楚。

## 三種實際幫到手嘅回應

| 使用者需要 | MedSafe 點樣幫手 |
|---|---|
| **睇清楚** | 拍照或者搜尋藥品，自己核實產品同用藥途徑，再睇成分同有來源嘅資料；有文字同裝置支援嘅語音。 |
| **搵到有根據嘅提示** | 將揀咗嘅藥逐對核對，保留複方入面所有成分，列出適用規則同出處；禁忌、建議避免、風險增加同先諮詢會分開講。 |
| **知道邊度未查清楚** | 身份、途徑、成分對照或者規則未齊，都會講明；可以整一張有藥品清單同問題嘅卡，帶去問藥劑師。 |

見到風險提示，唔代表要自己停處方藥；查唔到規則，亦唔代表可以安全一齊食。

## 即刻試下

搜尋 `HK-53362` 同 `HK-53319`，對照示範材料確認產品，睇下共同成分同出處。再加另一款藥，留意每一對有乜結果、仲欠啲乜。亦可以影一個清晰、冇個人資料嘅藥盒，睇清楚識別結果先確認。

問下用途或者部分副作用，聽錯字就先改返，再打開藥劑師問題卡。大字、可修改嘅識別文字同手動輸入，令相機或者語音用唔到時都可以繼續。

手機網頁唔使登入。主動下載離線包之後——目前約 **52.7 MiB、53 項資源**——已儲存嘅目錄、規則同瀏覽器識字可以斷網用。瀏覽器語音識別可能會用服務商網絡，使用前會講明，斷網就停用；廣東話朗讀要睇裝置有冇本地聲音。Apple Silicon Mac 版裝好軟件同模型後，可以喺本機做廣東話識別。

## 資料、依據同驗證

| 資料層 | 目前範圍 |
|---|---|
| 香港官方註冊目錄 | **14,269 個產品**，資料快照為 2026 年 9 月 25 日 |
| 成分記錄 | 23,835 條；2,081 個唔同嘅原始成分文字 |
| 成分教育資料 | **14 個成分資料卡**，附有來源 |
| 核對知識 | **14 條有出處嘅規則草案，全部仲等緊專業複核** |
| 示範製劑 | 13 款，包括複方 |
| 多藥處理 | 最多 **12 款產品、66 對核對記錄** |

目錄嚟自香港衞生署藥物辦公室；規則同教育資料逐項引用香港藥物辦公室、DailyMed 標籤記錄同 MedlinePlus/ASHP。每條提示都保留證據層級、適用途徑同來源。海外標籤會標明來源地區。[完整資料清單](../../data/data_inventory.json) · [規則記錄](../rules/README.md)。

識字同語音模型只係幫手輸入。醫學內容用列明嘅成分同義詞同限定用藥途徑嘅規則處理，方便逐項睇依據。[核對邏輯](../decision-logic.md)。

目前通過 **41 項多藥檢查、16 項公開瀏覽器流程檢查同 16 項手機離線工程檢查**，亦做過公開網站斷網驗證。呢啲係受控輸入下嘅軟件檢查。**真實手機、長者觀察同臨床驗證仲未完成**，未有證據話已經減少用藥錯誤或者改善患者情況。計劃中嘅廣東話照顧者訪談，只能支持嗰位參與者嘅經歷，唔可以用嚟推論外籍家庭照顧者嘅情況，亦唔等於做咗長者研究。[工程驗證記錄](../../qa/engineering-validation-summary.json)。

系統唔會評估個人劑量、完整禁忌、肝腎調整、孕哺或兒童方案，亦唔會評估三款或以上藥物同時產生嘅高階相互作用。註冊目錄齊全，唔等於臨床相互作用資料庫齊全。
