# 队友试用与反馈

公开网页已上线：[点这里试用](https://med-safe-hacku-2026.stashes-primers-4n.chatgpt.site)。直接把链接发给队友，不用 GitHub 帐号。手机先用 Safari／Chrome 打开，允许相机只是可选项。不要给真实患者作服药建议。

建议先试三条路径，每条约一分钟：

1. 搜索 `HK-53362` 与 `HK-53319`，核对两款产品及实际途径，查看共同成分与出处。
2. 添加自己的演示药品，观察有规则提示和没有覆盖的药对是否都清楚；确认系统没有把“查不到”写成可合用。
3. 打开单药资料，用文字或可用的粤语输入问用途／副作用；确认转写后再回答，下载药师问题卡。

随后拍一张无个人资料的演示药盒，比较注册号／成分是否识对。相机失败时用“选图片”或手动搜索。不必为试用购买处方药。

离线使用步骤及发布状态见 [offline.md](offline.md)。下载网页包不代表手机已经备好离线缓存，更不代表本地粤语模型已经安装。

反馈请提供：手机型号与系统、浏览器、操作步骤、预期、实际结果及是否卡住；截图先去掉姓名、电话号码及处方个人信息。最有用的问题包括字是否够大、哪一步不知道怎么继续、有没有误以为安全、能否找到出处、能否把结果讲给药师。公开 GitHub Issue 不要上传患者媒体或私密问句。
