## 1. 实际会离开设备的东西

| 动作 | 在哪里发生 | 离开设备的数据 |
|---|---|---|
| 目录查询与规则核对 | 浏览器内，使用已下载的数据 | **无** |
| 拍照与文字识别（浏览器） | 设备端，由随包的 Tesseract 完成 | **无**。原图由浏览器处理 |
| 拍照与文字识别（Apple Silicon Mac） | 同一台机器上的本机服务 | 只到该机器的 `localhost`。**临时文件随请求删除** |
| 浏览器语音输入 | **浏览器 `SpeechRecognition` 可能由厂商服务器处理** | **录音可能到达浏览器厂商。** 界面会说明，且每次征求同意 |
| 语音输入（Apple Silicon Mac，本地模型） | 本地 Qwen3-ASR | 模型装好后**无** |
| 语音输出 | 设备自带声音 | **无** |
| 打开外部引用链接 | 来源网站 | 对该网站的一次普通网络请求 |

**没有应用后端存储患者数据。** 正常的目录与规则使用没有服务端患者存储。

**有一件事确实总会离开**：请求公开站点本身，会把普通的访问元数据（例如 IP 地址）暴露给静态托管服务商。任何托管页面都无法避免，被问到就照实说。

---

## 2. 不能含糊的那条界线

> **网页语音识别不是全离线。**

浏览器 `SpeechRecognition` 可能由浏览器厂商的服务器处理。只有在界面说明之后才会启动，并就该次使用征求同意。**断网时应当改用打字输入。** 产品绝不能把网页粤语识别说成全离线。

本地语音（Apple Silicon 方案）不同：模型装好后在本机运行。只有设备报告存在本地声音时，才用它做朗读。

## 3. 离线行为

| 场景 | 行为 |
|---|---|
| 数据包下载完成后的完全离线 | 目录查询、规则核对、手动输入与药师问题卡都可使用。浏览器识字用随包资源。**外部引用链接打不开**；本地摘要、日期与章节出处仍在 |
| 网络不稳定 | 已下载数据的功能等同离线；外部链接可能失败 |
| 数据包没有下载 | 只有已经缓存的内容可用。页面上的离线下载入口是状态的权威指示 |
| 离线安装体积与缓存完成度 | **从随包界面读取，并在该设备上实测。** 不要在未经该设备实测的情况下引用任何数字 |

**测试状态，说准确**：公开网址已在**匿名 Chromium 会话**中完成完整离线下载、断网重开与断网查药；同时补充 **9 项网站跳转回归检查**。手机离线升级通过 **16 项核心工程检查**，涉及 **53 个缓存资源、约 52.7 MiB**。**尚未完成真机测试。** 该套件声明的范围是：Chromium 桌面端模拟 320/390px、对合成素材做真实 OCR、语音识别为模拟、该套件内 service worker 被屏蔽。**它不是 iOS / Safari / Android 真机测试，不是患者测试，也不是临床验证。**

---

## 4. 不得放进缓存的东西

个人药品选择、用户提问、录音与图像**都不应加入应用缓存**。缓存是给目录、成分资料、规则与识别资源用的，不是给用户个人情况用的。

## 5. 合规说明

| 项目 | 说明 |
|---|---|
| 香港《个人资料（私隐）条例》（PDPO） | 个人健康信息默认不上传。产品的设计使患者数据存储没有必要 |
| 照片是否留存 | 浏览器：在设备端处理，不上传。Mac：临时文件随请求删除 |
| 用户能否删除 | 没有服务端患者记录可删。清除浏览器或应用缓存会移除已缓存资源。**各浏览器缓存的保留与淘汰行为仍需核实** |
| 第三方服务 | 公开站点的静态托管服务商；仅在启用浏览器语音识别时的浏览器厂商；以及用户主动打开的外部引用站点 |
| 已安装的模型权重 | 可选的本地语音模型（约 0.7 GB）安装在用户自己的机器上。**安装过程不需要任何患者信息** |

## 6. 路演时怎么说

一句话，可以直接用：

> **"There is no backend holding patient data. In the browser, the photograph is recognised on the device and does not leave it — because a photograph of medicines is personal health information."**
>
> 中文：**「没有后端保存患者数据。在浏览器里，照片在设备端识别，不会离开设备 —— 因为药品照片属于个人健康信息。」**

被问到语音时，不要含糊：

> **"Web speech recognition may be processed by the browser vendor, so we disclose that and ask for consent each time. When offline, you type. The local Mac option keeps audio on the machine."**
>
> 中文：**「网页语音识别可能由浏览器厂商处理，所以我们说明这一点，并且每次都征求同意。断网时用打字。Mac 本地方案让音频留在机器上。」**

不要声称网页语音那条路是离线的。这是这里唯一经不起一问的说法。
