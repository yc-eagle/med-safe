# 队友五分钟试用

**手机直接打开：[MedSafe](https://med-safe-hacku-2026.stashes-primers-4n.chatgpt.site)**。不用登录，也不用下载 GitHub 文件。公开网页已上线；手机离线升级已公开发布至同一网址。

1. **第一分钟：认药。** 搜索 `HK-53362`，检查产品名称及成分，再加入 `HK-53319`；按演示材料核对并选择途径。它们是任务示例，不是个人用药建议。
2. **第二分钟：看结果。** 查看共同成分、警示与出处，确认你能看懂哪些已提示、哪些没有检查。尝试添加另一款产品，看看未覆盖的药对是否清楚。
3. **第三分钟：拍照。** 用不含姓名或处方个人资料的演示药盒拍照，核对识别出的注册号和产品；拍照失败就用选图片或手动搜索。
4. **第四分钟：问清楚。** 打开单药资料，打字问用途／副作用。有浏览器语音时会先说明可能联网；药名听错先改字。试大字模式并下载药师问题卡。
5. **第五分钟：给反馈。** 告诉我们手机型号、系统和浏览器，以及最卡的一步、看不懂的一句话、是否误以为“没提示就是安全”。截图请先去掉个人信息。

**离线试用：** 首次使用时，在产品的离线入口明确完成约 52.6 MiB／47 项资源下载，再加到主屏幕并开飞行模式重新打开，试查药与拍照识字。没有完成提示前不能当已离线；浏览器语音识别断网禁用，朗读取决于是否有本机粤语声音。当前自动化断网流程检查通过，**真实 iPhone／Android 尚未实测**，你们的反馈很重要。

**目前边界：** 14,269 条注册产品资料不等于完整医学知识库；14 条规则全部待专业复核，不评估个人剂量或全面禁忌。不要拿测试结果自行决定服药、停药或换药。“查不到”表示当前范围没有答案，应带药品信息问药师。
