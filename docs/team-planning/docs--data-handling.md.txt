## 一、默认：什么都不离开设备

| 动作 | 在哪里发生 | 离开设备的数据 |
|---|---|---|
| 拍照 | 设备本地 | **无** |
| 文字识别 | 设备本地 | **无** |
| 药品信息查询 | 本地数据 | **无** |
| 相互作用核对 | 本地规则 | **无** |
| 语音合成 | 设备本地 | **无** |
