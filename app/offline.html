如何打開、下載與離線使用

最方便：把這個網站連結轉發，對方用瀏覽器打開即可。毋須 GitHub 帳戶；拍照時由瀏覽器詢問相機權限。相機不可用時可選照片或手動輸入。

手機離線：先聯網準備一次

  1. 回到產品首頁，按「準備手機離線」，保持頁面開啟，等待約 53 MiB 資源下載並校驗完成。
  2. 看到離線就緒後，iPhone Safari 按「分享 → 加入主畫面」；Android Chrome 選「安裝應用程式」或「加入主畫面」。
  3. 先開啟一次，再關閉網絡試用。可查藥、逐對核對、拍照識字及下載問題卡。
  4. 手機離線時停用瀏覽器錄音轉寫；朗讀只有裝置已有粵語聲音時可用。個人照片、錄音及藥品選項不會加入離線快取。

瀏覽器或系統可能清理網站儲存；請在外出前重新確認離線狀態。這不是已經完成 iPhone／Android 真機驗證的宣稱，歡迎隊友實機反饋。

下載完整程式

打開團隊 GitHub，點 Code → Download ZIP。解壓後按 README 操作。

模式可用功能首次準備
公開網頁查药、成分資料、多藥逐對規則、瀏覽器識字、問題卡；語音依裝置上網載入網站及識字資源。需先手動準備並校驗離線資源，未完成時不能保證離線開啟
離線 HTML打開 app/index.html：查藥、資料、规则、問題卡下載程式。file:// 的相機／識字可能被瀏覽器限制
Mac 完整本機版拍照識字＋本機粵語識別／朗讀＋全部查詢Apple Silicon Mac；雙擊「啟動演示.command」。先按 README 安裝語音環境及模型，準備完成後可斷網運行

如系統不允許雙擊腳本，可在該資料夾執行 python3 server.py。首次編譯 Apple OCR 需要已安装開發工具。完整安裝步驟、依賴與固定模型版本見 README；不能把「下載 ZIP」誤解成所有電腦已備妥語音模型。

離線時原始來源外鏈不能打開，但隨程式保存的事實摘要、規則、來源日期和章節仍可查看。不需要會員、API Key 或雲端帳戶。Windows / Android 尚無隨包本機粤語模型版。
